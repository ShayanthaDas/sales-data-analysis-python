# Sales Data Analysis (Python)

## Overview

This project is a simple sales data analysis using Python. The goal was to explore sales performance, identify patterns, and understand what drives revenue in the dataset.

I focused on cleaning the data, doing basic analysis, and turning it into useful insights.

## What this project is about

* Understanding overall sales performance
* Finding top-selling products
* Analyzing category-wise performance
* Identifying trends in sales data
* Practicing Python-based data analysis

## Tools used

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook

## Workflow

1. Data loading
2. Data cleaning
3. Exploratory data analysis
4. Sales trend analysis
5. Product and category analysis
6. Visualization

## Key insights

* A small number of products generate most of the revenue
* Some categories consistently perform better than others
* Sales trends show clear variation over time
* Certain products have low performance despite availability

## Files in this repo

* sales_analysis.ipynb
* dataset.csv
* CASE_STUDY.md
* charts/

## What I learned

This project helped me get more comfortable with Python for data analysis. I also learned how to move from raw data to simple business insights step by step.
